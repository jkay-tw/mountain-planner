## 資料契約

- `data/staging/idea002/classic-route.schema.json`：單一路線方向的 schema；`occurrences.position` 從 0 開始，Sheet 原 position 從 1 開始。
- `sheet-snapshot-20261120.json`：原始選取列及使用者 N/T 文字。
- `decisions-20261120.json`：本輪明確決策，與原文分離。
- `classic-routes.candidate.json`：可重現的候選目錄，含順／逆兩個結構視圖，仍共用一個 Route ID。
- 引用以有向 Node ID 配對、graphDigest 及 source 版本鎖定；不複製權威座標或方向分鐘。幾何引用 spanId、位置範圍及 reverse，來源幾何 SHA-256 另存。
- 反向只反轉已展開的 occurrence，再查每一條實際反向邊；不重新最短尋路。幾何也重新檢查是否可逆。圖上存在反向邊不代表現地通行已核實。
- `candidate-review` 只表示此資料版本沒有已知結構缺口，仍待走法與來源審核；`blocked` 不能套用；`manual-time-required` 表示存在具來源、無上河分鐘的人工連接。
- 所有輸出均是 candidate，未由測試結果提升為 verified。requireVerified 會檢查審核人、日期、證據及方向／幾何缺口；正式整合仍須人工審核，不存在自動發布工具。
- R052 目前僅為 `multi_segment` 阻擋項。完整 walking／vehicle parts 與端點待來源審核後增補；本輪的車行查值／時間函式尚未接入 DAY 計算或匯出，現有 UI 行為不變。
- 未來套用應沿用 IDEA-003 `showInTable`。Phase 1 不建立第二份顯示狀態，不把候選加入現有 manifest，不改舊行程。
