# v0.8.8 正式版（2026-11-04）

## 更新

- 新加入的上河路段固定使用加入當下的每日預設係數，含尋路及快速加入的中間節點。修改預設係數不會改動既有路段，也不會取消已選好的下一個節點。
- 規劃分鐘數顯示在前，逐段係數顯示兩位小數。鍵盤上下鍵每次 ±0.10（0.85 → 0.95），仍可手動輸入 0.85，並保持輸入焦點。
- 有來源資料時可來回切換一般、慢速、重裝參考時間，保留該段係數；沒有上河時間的手動路段仍可輸入分鐘數。
- 舊檔與暫存保留每段原有規劃分鐘數，包括手動調整時間；主動編輯係數後才重新計算。JSON、時間軸與 Excel 使用一致的計算。
- 新 Day 2 起預設銜接前日；前日無終點時保留待銜接，之後跟隨終點變更並保留使用者行程。舊行程保留原銜接選擇。
- 手機可直接輸入出發時間（0630、630、06:30），並保留系統時間選擇器；改時間時不移除選擇器。手機輸入欄維持 16px，避免 iPhone 自動放大。
- 重繪前後保護可見 Day 的位置，改善 iPhone 跳至地圖附近的情形。Issue #6 繼續追蹤實機結果，發布不等於宣告所有 iOS 情境已驗證。
- 路段係數欄寬 68px；中寬視窗 Day 標頭合併控制列，統計在下一行；少量節點剖面圖縮短留白，PNG 同步使用縮短畫布。

## 使用與相容

正式版：https://jkay-tw.github.io/mountain-planner/

沿用正式版暫存鍵，Preview 暫存仍獨立；如要搬移 Preview 行程，先在 Preview 匯出 `.mplan.json`，再於正式版匯入。重要行程請先匯出備份。資料與地形範圍沿用 [v0.8.7](v0.8.7_RELEASE.md)，本版沒有新增或重新核實路線來源。
