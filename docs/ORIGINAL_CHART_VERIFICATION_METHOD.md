## 逐圖核對

1. **讀取正式來源**：以圖號、圖檔 URL、實際修訂版、取得／檢查日期建來源紀錄。不得將原圖當作已授權可重新發布的素材。圖檔無法讀取則註明，不能假設同路徑舊版本有效。
2. **對照起迄地點**：將候選 `group/from/to` 對到圖上的實體節點。必要時核對前後相鄰節點、共用 Node ID、不同名稱別名。所有「登山口」「三岔路口」等重名地點必須有更強依據。
3. **雙向分開抄核**：依原圖箭頭讀取 `A→B` 與 `B→A` 的分鐘數；不能把反向時間自行對稱，也不能以其他圖的相同數值取代原圖。圖中「重裝」「慢速」等時間另記條件值，不覆蓋標準步程。
4. **獨立交叉比對**：第一遍只讀原圖，第二遍才比較候選和其他圖組的重疊方向；同組重複、跨圖分鐘數差異、缺反向、分叉路徑、車行段須另列異常。來源資訊不明或圖上文字辨識不清者保持待查，必要時才請使用者協助。
5. **留證據及版本**：每個有方向的路段記錄官方 `chartId/chartURL`、原圖節點標籤、分鐘數、箭頭方向、是否車行、情境備註、`reviewedBy/reviewedAt`、核對細節及來源修訂，並保留前一版記錄和改動原因。
6. **編譯門檻**：待查項目不進已核實步行路網；編譯結果再檢查去回分鐘、節點唯一性、跨圖物理 Node ID、路徑方向、時間保存及匯入舊檔。未經確認的來源不應顯示為已核實。

## 非同一來源的多重檢查

- **結構檢查**：JSON 欄位、正數時間、方向定義、節點 key。
- **邏輯檢查**：同一張圖內去回方向、平行／重複路段、車行與步行、孤立節點。
- **跨圖檢查**：僅比較兩端實體 Node ID 均已由使用者審核相同的路段。
- **官方原圖查證**：與上述候選檢查獨立，比對該路段原圖兩個箭頭和特殊註記。
- **版本回歸**：更新圖檔或路段時，以差異報告比較，避免無意間改變舊行程儲存的實際時間。

前三項即使全部通過，也不等於完成第四項。程式能自動整理、互相比對、優先排序；官方圖是影像資料，沒有穩定的機器可讀路段 API，故無法保證全量自動讀圖的精確度。模糊文字及接線須採人工目視複核。
