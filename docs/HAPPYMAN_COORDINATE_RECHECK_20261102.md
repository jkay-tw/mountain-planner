## 複核方法與保留項目

以官方 Mapsforge 0.25.0 reader 讀取使用者提供的二進位圖層，篩出與缺失節點名稱相關的 GPX 航點。只清除航點序號、時間及高度附記，不將山屋、營地、最高峰、基點峰合併。既有已選定點位作為相鄰路線比對依據；跨圖共用 Node ID 保持原樣。

具名山峰候選群直徑上限 150m，其他具名點 80m；泛稱營地／岔路／最低鞍部仍需至少兩個相鄰定位點；無步行鄰點且只有單一來源的接駁地點保留待查。用既有步行時間排除明顯不合理的遠點，不反推或插值座標。不同群仍有衝突時保留缺失。新增點是規劃標示座標，尚非全路線步道線形或 DEM 成果。

Happyman 來源可能與既有 GPX 共用上游資料；來源數不等同獨立實測數。圖層日期為 2024-08-13，未據此推定設施現況。原始 .map 與全圖 POI 資料庫不納入專案，僅保留必要的匹配來源與原標名。

## 重現

Java 17 以上，classpath 包含 Maven Central 的 org.mapsforge:mapsforge-core、mapsforge-map、mapsforge-map-reader 0.25.0。

```sh
java -Xmx2g --class-path '/path/to/jars/*' tools/ExtractHappyman.java Happyman.map all-pois.ndjson 22.0 120.0 25.4 122.1
git show 9077ba5:data/geometry/all-route-coordinates-v1.json > baseline.json
python tools/import_happyman_points.py Happyman.map all-pois.ndjson matched-points.json --baseline baseline.json
python tools/recheck_happyman_coordinates.py baseline.json matched-points.json
```

匯入階段請使用該基準版本的缺失清單；提交的來源子集可直接用於重跑 recheck，無須散布全圖。
