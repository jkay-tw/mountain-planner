## 功能與操作

- 快速加入列出已連通步行路網前後兩段內的候選；只顯示「＋ 名稱」，不再有圖組、節點編號、經由地點或其他備註。辨識仍使用Node ID。
- 全路網行程表逐段顯示距離／↗／↘，每日顯示加總。缺失時間與地形資料不以0取代，部分資料會明確標示。
- 每日表格下方按「查看高度剖面」，或在「行程地圖與 GPX」下展開每日高度剖面。節點旁直接標示名稱、累計距離、DEM海拔，含格線及避碰標籤。
- 地圖可切換OSM／魯地圖、開關已收錄全路網參考線、依日顯示。Day標籤常駐；節點顯示名稱／海拔，詳細模式增加 `TWD97 (X, Y)`，沒有第四行設施備註。來源備註保留在地圖說明與來源檔。
- GPX 含已定位節點與沿線DEM高程。不同來源路段與不同天分段輸出，不跨缺口補直線；只有定位點時可明確選擇節點GPX。
- 手機備註與「⋯」排在該行程下一行；中視窗維持地點、抵達、時間與距離／升降同列。
- Excel：標題「登山行程規劃」、A4直向、9欄、獨立距離／上升／下降、每一天重複項目標題、固定行程／統計列高15.75pt、格線與辨識顏色、解除凍結。規劃／上河採 `[h]:mm`，123分鐘顯示2:03；手機與電腦呼叫相同匯出程式。沒有資料版本備註或來源欄。
- G19神池營地與小關山雙向可自行填時間；上河時間保持空白。退休節點舊行程快照、匯入匯出、每日備註及手填分鐘保留。

## 來源核對與修正

6項修正另存 `data/geometry/sources/coordinate-corrections-v08.json`，不覆寫歷史729點稽核或變更Node ID：大水池登山口、嘉明湖岔路口、烏瓦拉鼻溪、玉林橋大崩壁、屏風山新登山口、果園登山口。前四者分別涉及同名登山口、布新岔誤配、溪流平均點及崩壁平均點；後兩者排除石門側舊標與另一條路線的同名果園點。完整原座標、原來源、原標名及修正理由均保留。

OSM線形採全臺Geofabrik快照，尊重foot/access、障礙與步行單向；不把鄰近但未共用OSM節點的步道接通。節點標示與真實步道錨點分開，不畫離徑連線。新線形使用沿途約30m取樣、雙線性DEM內插與三點平均（端點固定），逐段累計上升與下降；既有雪山7點與7條來源線形完全保留。

4組歷史補線為：博可爾山—博可爾草原、中央尖山東峰—中央尖鞍部、七彩妹池—七彩湖、三岔路口—巴奈伊克山屋。只取來源中連續可對應的片段，不採完整GPX其他探勘段；原檔雜湊、片段證據／剪取索引及來源網址位於 `reference-route-clips-v08.json`。這些來源與OSM的歸屬分開，未宣稱歷史GPX整體採ODbL或目前開放。

## 重建

Python 3.11+，地形建置需要 `numpy==2.3.5 scipy==1.17.0`，PBF擷取另需PyOsmium。原始PBF、DEM、完整.map與完整GPX不放入Git；使用來源檔記錄的SHA256核對原檔版本。HGT需含本版使用的全臺瓦片，不能僅提供雪山單瓦片。

```sh
python tools/extract_walking_network.py /path/to/taiwan-latest.osm.pbf /path/to/walking-network.json.gz
python tools/build_full_terrain.py /path/to/walking-network.json.gz /path/to/hgtmix.zip
python tools/apply_reference_routes.py /path/to/hgtmix.zip
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

`clip_reference_gpx.py` 可從公開來源檔重剪單一連續GPX段；原始Happyman行跡可用 `ExtractHappymanTracks.java` 與 Mapsforge 0.25.0 三個官方reader/core/map套件讀取。發布重建時使用已審查且附來源的4條剪取片段，不需重新散布整張圖層。

`build_planner_geometry.py` 僅供建置雪山種子，CLI需 `--seed-output` 指定其他路徑，會拒絕覆寫完整地形檔，避免重建退回只有雪山。
