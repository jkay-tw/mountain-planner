# v0.8.7 正式版（2026-11-04）

## 更新

- 統一圖組行程與全域步行路網，支援快速加入、手動未連通段及保留規劃時間。
- 行程地圖呈現每日路徑、節點、海拔與 TWD97 座標，支援底圖切換、參考 GPX、高度剖面及圖片複製／下載。
- 行程表與 Excel 顯示距離、累積上升與下降；支援行程備份、複製文字與瀏覽器支援時的另存視窗。
- 浮動工具列提供復原、重做及常用匯出功能。

## 資料與限制

現有資料包含 724 個現行節點，其中 622 點已定位並有 DEM 估算海拔；654 組參考線形含 42 組跨未定位節點線形。仍有 17 組缺端點錨點或來源線形，明細見 [v0.8.1 座標更新](v0.8.1_COORDINATE_UPDATE_20261104.md)。跨未定位點的分段距離無法精確分配；車行不計入步行路網。路徑與時間是規劃參考，不代表即時路況或現地導航。

正式版保留既有正式版瀏覽器暫存，Preview 暫存獨立；如要搬移 Preview 行程，請從 Preview 匯出行程備份，再在正式版匯入。匯入會取代目前行程，建議先匯出正式版備份。手機及不支援選擇儲存位置的瀏覽器維持一般下載。

座標更新方式見 [局部更新流程](COORDINATE_UPDATE_WORKFLOW.md)。
