# 雪山主東線 GPX 試點

狀態：**候選、研究用途，尚未加入規劃器路網或自動 GPX 匯出**。
經緯度是 WGS84 參考位置，並非上河圖原始座標、現場測量或精確導航保證。不得依名稱自動合併不同地點；每個位置應個別核實、保存不確定性及資料來源。

## 實際軌跡與來源

- 候選 A：[xue_main_east.gpx](https://github.com/chihjolin/allpass/blob/61cf74f522ebc7c0a81204f73dc729670eb3260b/etl/init/data/gpx/xue_main_east.gpx)：164 個點，約 9.67 公里，最大相鄰點間距約 317 公尺；線形採樣稀疏，記錄終點 GPS 高程與山峰標高不同，不宜將其高程作為官方高度。
- 候選 B：[雪山主東峰步道.gpx](https://github.com/jiasyuanchu/Trail-Finder/blob/da5717ba34881376d7fb6536fcb4c6089806c82a/path/%E9%9B%AA%E5%B1%B1%E4%B8%BB%E6%9D%B1%E5%B3%B0%E6%AD%A5%E9%81%93.gpx)：4,038 個點，約 22.51 公里；含往返及營地移動。擷取前 2,057 點作為上山試點，約 11.37 公里，最大相鄰點間距約 87.5 公尺。試點仍可能包含繞行及訊號誤差，不能視為完整、已核實山徑。
- 兩筆紀錄整體走向接近：候選 A 的各點到候選 B 最近記錄點距離中位數約 2.8 公尺，第 90 百分位約 8.3 公尺，最大約 31.9 公尺。這只是空間接近檢查，不證明所有路段正確，也不代表紀錄者彼此獨立測繪。
- GPX 試點只保留軌跡點與記錄海拔，移除個人時間資料。第三方資料的再散布條件尚未確認，原始或衍生 GPX 不加入公開 repository；私下研究資料與正式可發布資料分開處理。

政府資料來源：[雪霸國家公園登山步道路線圖](https://data.gov.tw/en/datasets/90145)，提供機關為國家公園署，採政府資料開放授權第 1 版；其目錄連往 TGOS SHP 圖資，但本次執行環境未能下載並檢查壓縮檔，因此不能宣稱已取得或比對該路網。

## 重現與下一步

`tools/gpx_track_inspect.py` 可讀取 GPX 1.1 實走紀錄、分開處理 track segment、檢查相鄰點間距與選取連續的點，匯出時去除時間。不要拼接不同段或把節點直線當實際路徑。原始第三方 GPX 不納入版本庫；使用者如自行取得來源檔，可在本機執行。

下一步為取得可使用且可追溯的路徑圖資、核實山屋與「圈谷底部」對應位置，進而設計與行程節點相接的路徑與缺漏提示，再整合圖層切換及依行程匯出 GPX。未找到資料的路段需明確標示，不能自動補直線。

獨立 `snow-gpx-pilot.html` 提供 GPX 匯入與地圖檢視，可切換 OpenStreetMap 和魯地圖；GPX 只在瀏覽器處理，地圖圖磚由對應的線上服務供應。各個 track segment 分開顯示與計距，不會自行連線補缺。此頁不是行程 GPX 匯出，亦不把匯入軌跡或路點寫入既有行程。
