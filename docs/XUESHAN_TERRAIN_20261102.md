# 雪山距離、升降與高度剖面（v0.7.28 Preview）

## 來源與圈谷位置

使用者提供兩組圈谷底部座標，經比較發現不一致：度分秒 24°24′18.6″N 121°14′11.0″E 為 24.4051667,121.2363889；TWD97 TM2 zone 121（EPSG:3826）273977,2698069 轉為 WGS84 24.3884918067,121.2363802267。使用者本次明確選擇 **以 TWD97 為準**。因此將該點作為使用者指定的圈谷底部位置，並非由 OSM 名稱推定。

位置投影至既有雪山候選線形，偏移約 5.4m；保留指定座標與步道錨點，沒有畫離徑直線。原三六九—主峰跨度拆成圈谷前後兩段；保留歷史直接跨度，使用相同剖面拼接以維持總量一致。OSM 身分、來源快照與上河時間未修改。

魯地圖官網 https://rudymap.tw/ 列出 DEM mix v2026，本島約30m、離島90m。由 https://rudymap.tw/v1/hgtmix.zip 下載成功，實際取得 N24E121.hgt，3601×3601 signed big-endian int16、一角秒格網。壓縮檔與格網 SHA-256、取樣方法保存於衍生 JSON 的 terrainSource。原始高程格網不放進公開 repository。

來源程式及使用說明：https://github.com/alpha-rudy/taiwan-topo 。圖資署名魯地圖並連回官網。官網說明內政部地形資料及相關授權；本次檔案之垂直基準與現地精度未另行驗證，不把標稱30m格網當30m垂直精度。下載得到的格網日期亦不代表原測繪日期。

## 可重現計算

`python3 tools/build_xueshan_terrain.py /path/to/hgtmix.zip` 從原 OSM 幾何與下載的格網重建 `data/geometry/xueshan-terrain-v1.json`。原始幾何 v1 保持不動，以保留舊版研究與測試。

- 距離為沿 OSM 折線的水平地表位置距離（球面距離），不是兩端直線，也不是三維地表長度。
- 每30m沿路徑取樣，補保留路段起終點；用雙線性插值取得 DEM 高度。NoData／範圍外拒絕計算，不填0。
- 三點移動平均平滑內部樣本，固定端點；分開加總正與負高度差。每段保留剖面樣本，來源與計算方法可查。
- 反向將剖面反轉，爬升／下降交換；跨日及往返依行程實際次數計算。畫面距離顯示0.01km、升降取整m，底層保留未取整值再加總，因此顯示的分段整數之和可能與整日顯示相差數m。
- 手動／車行／未收錄幾何不吸附、不補線；統計明示「已知部分」，剖面不連缺口。這批只有雪山主東線的高程資料，不冒稱其他圖組已有高程。

## 行程與匯出

- 每段備註欄下方顯示距離／上升／下降，原備註保持可編輯且不被自動文字覆寫。
- 每天頁尾顯示距離／上升／下降加總；地圖區塊提供各天高度剖面。
- Excel 同一行的備註格附加相同地形統計、保留原註記；每日統計附加同一組加總。未載入地形資料時不宣稱具有統計。
- 修正圖層選擇器 input 繼承全域38px高度造成的留白，保留鍵盤 focus-visible。
- 正式版根目錄與 PR 不動；僅 main/preview 發布。

## 驗證

新增數值例題、反向交換、多日切分守恆、舊直接長路段相容、手動缺漏與剖面不補線、Excel 產生路徑及原備註不變測試；Python 檢查 HGT 位元組、格網方向、插值、NoData、取樣端點與剖面接點。

實際驗證：95 個 JavaScript 與56個 Python 測試通過；開發分支 CI 通過。用產品同版 ExcelJS 4.4.0 及 exportExcel 實際產生 XLSX，重新讀取與獨立 ZIP/XML 檢查皆成功（A1:G13、六段備註及一列每日統計、原註記保留）。瀏覽器確認反向10.10km、升143m／降1874m；兩日往返各6.65／13.56km；剖面入口、圈谷定位及圖層可載入。Excel 視覺與最後部署狀態仍依後續記錄。
