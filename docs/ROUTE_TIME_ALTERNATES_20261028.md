# 路段標準時間與條件式參考時間（v0.7.10）

資料依據：2026-10-28 使用者逐項確認的 15 個疑義項目。核對紀錄：
- `data/audits/user_reviewed_time_overrides_20261028.json`：16 組「圖組＋去回時間」、32 個方向；同一地點可能在不同圖組重複記載。
- `data/audits/user_review_resolution_summary_20261028.json`：候選資料修正前後差異。
- `tools/apply_reviewed_times.py`：在私人候選資料執行批次修正，**不寫入正式路網**。

## 資料意義

- `go`：`from → to` 的標準上河參考分鐘數；`back`：`to → from` 的標準分鐘數。
- `alternates.forward`／`alternates.reverse`：同一方向在特殊條件下的補充參考，`kind` 是 `slow` 或 `heavy_pack`。**不能取代標準分鐘數，也不能被當成反向時間。**
- 編輯器可在已獨立來源核對、正式載入的路段資料中接收 `timeAlternatives: [{kind:"slow",minutes:350}]`。
- UI 保留「上河標準分鐘數」及日係數；條件式按鈕僅對當前路段的 `actualMinutes` 施加數值，使用者仍可手動編輯。既有 `schemaVersion:1` 不變。
- 路線正規化會保留來源及條件式估時資訊；若某路段未包含此資訊，介面不會憑空顯示選項。

## 圖組標記

原始候選 JSON 內確實有 `八通關越嶺` 名稱，但不能因為它存在就宣稱對應 G01～G20 其中一張正式圖。目前記為 `unmapped_candidate_group`、禁止作為已確認官方圖組公開尋路。

## 目前狀態

原始 869 筆候選時間在私人複核檔中依使用者值修正後，同組重複方向時間衝突已降至 0；以已確認共用 Node ID 兩端節點比對，跨圖方向時間也無剩餘衝突。這是**內部一致性**，不表示所有步程都已與上河官方原圖逐段核對。

慢速 350、260 分與重裝 160、60 分僅為使用者確認有標註的條件式參考值。後續若要公開發布，仍須補足逐方向的來源證據、檢查授權，並通過圖路網驗收。
