## Routing engine
`js/crossmap-routing.js` builds a separate directed graph:
- Uses explicit local node IDs and only reviewed canonical IDs for possible shared physical locations.
- No name-based joins, no transfer links inferred from matching labels.
- Defaults to `allowCrossMap:false`, so even reviewed same-place nodes stay separate until explicitly enabled for developer testing.
- Requires each segment to specify `travelMode:"walking"`, `verificationStatus:"verified"`, and finite nonnegative `minutes`.
- Excludes vehicle segments, pending/unverified segments and assumed reverse directions; preserves source and route provenance.
- Fails if confirmed same-place metadata violates an explicit user exclusion.
- Developer-only tests can enable `allowCrossMap:true` with independently verified data on both sides.
