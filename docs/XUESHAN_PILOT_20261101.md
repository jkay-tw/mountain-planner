# 雪山試點工作紀錄

使用者確認 G04 與 G05 的以下地點為同一實體：武陵農場／武陵農場·遊客中心顯示為後者；雪山登山口／雪山登山口管理站顯示為「雪山登山口」。現有 ID 必須有可回溯遷移映射，舊行程節點與時間快照不得遺失。農場岔路↔武陵農場·遊客中心為車行 10/10；農場岔路↔武陵山莊車行 10/10；農場岔路↔雪山登山口車行 20/20；雪山登山口↔七卡山莊步行 70/55。

兩段雪山路線：七卡↔三六九經哭坡觀景台及雪山東峰共 255/160；三六九↔雪山主峰經圈谷底部共 200/140。保留長路段來源，但尋路應使用細分路段；已儲存的行程與手動時間不能自動改寫。尚未套用至路網。

地理資料候選：OSM 山徑及節點、林業保育署開放資料、魯地圖線上圖磚與可取得的雪山 GPX。線上底圖參考 https://tiles.rudymap.tw/ ，從 TileJSON 取得版本化圖磚與 attribution。國家公園雪東線資料 https://www.taiwan.nps.gov.tw/home/zh-tw/trails/21209.html 。尚未取得和比對可用的線形資料、節點座標及高程；未聲稱 GPX 試點已完成，亦不以直線代替山徑。
