# v0.7.25 分頁暫存修正

依使用者要求直接更新正式版。每分頁 sessionStorage 保存工作行程；重整優先恢復本分頁，新的分頁由 localStorage 載入最後修改備份。初始化、遷移及單純切換圖組不覆寫共用備份；修改、匯入、清除與復原會依行程差異更新備份。正式與 Preview 鍵維持隔離，舊 v1 暫存保持原樣。

不影響路線資料、Node ID、時間計算或行程檔格式。瀏覽器的「復原已關閉分頁」可能由瀏覽器恢復原 session；一般新開分頁會使用共用備份。若瀏覽器禁止儲存，無法保證暫存恢復。

驗證：`node --test tests/*.test.mjs`，涵蓋兩分頁、重整、複製分頁、新分頁、群組篩選、重設、舊資料遷移及不可用儲存空間。
