## 線形如何選取

`tools/build_xueshan_geometry.py` 以明列的 10 條 OSM way 建圖；只透過相同 OSM node ID 連接，不做最近點拼接。`1222030823` 為施工禁入線段，排除；選用 `1222030824`、`1222030825` 臨時步道。未選用附近捷徑、營地線、建築內步道、雪北與志佳陽岔線。是否現時開放應另查官方及現地，不能只依 OSM access tags 判定。

| 幾何段 | 候選線形距離 |
|---|---:|
| 登山口—七卡主線經過點 | 1,802.84 m |
| 七卡—哭坡觀景台附近 | 1,615.24 m |
| 哭坡—雪山東峰標示牌附近 | 1,023.49 m |
| 東峰—三六九附近步道（含臨時步道） | 2,204.75 m |
| 三六九附近步道—雪山主峰（圈谷底部路點未定位） | 3,458.18 m |

總計約 **10.10 km**，沿 687 個不重複連續點估算，最大相鄰距離約 63.1 m。這不是官方里程或精度指標。

最後一段明列行程順序 `三六九 → 圈谷底部 → 主峰`，使用完整 OSM 走廊；**不推定圈谷底部在走廊上的位置**。完整穿越可顯示整段候選線形並提示路點未定位；若停在／起於圈谷底部、跨日在此切段或中間含手動段，則不能裁切，必須報告缺漏。歷史行程中的直接 official 長路段也可對應同一完整走廊；不以此更動行程。

## 編輯器與 GPX 行為

- 統一編輯器可展開「行程地圖與 GPX｜雪山試點」，主動按載入後繪目前行程；不將地圖資料寫入行程。
- 依序處理 Node ID 與 official incoming；反向翻轉線形、跨日分 track，休息項目不改變線形。手動、車行、不匹配的邊、未知節點均不吸附。
- 圈谷底部未定位會常駐提示，GPX 不輸出該 waypoint。山屋的建築標示點與步道可能有偏移，GPX 描述保留這個差異。
- 未取得線形的段落報告缺漏。匯出部分 GPX 需明確點選並確認；每個 source span 獨立 trkseg，缺口不補直線。外部軟體若自行連段是其顯示行為，檔案沒有新增連接段。
- GPX 含 OSM attribution、ODbL、取得日期、候選與缺漏描述；不輸出 GPS 行走時間、不虛構海拔。連續路徑高程仍待可追溯的高程資料。
- 獨立 `xueshan-geometry-demo.html` 提供固定去程、回程、兩日及缺口範例，不讀寫原行程或暫存，方便操作驗收。
