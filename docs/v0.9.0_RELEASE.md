## 更新

- 發布已驗收的路網小地圖、節點標籤與引線；目前位置以綠色標記。密集節點為便於辨識會局部調整顯示，距離與方位僅供參考，直線僅表示連通。
- 快速加入呈現經由節點與返回方向，連續加入時保持小地圖展開。
- 發布休息與手動點的手機觸控拖曳、桌面工具列及窄視窗選單順序調整。
- 使用說明按鈕採醒目深綠底白字；重製局部截圖、編號框線、預設上河係數解說與圖片放大功能。
- 收錄座標／幾何來源指紋檢查、Preview 同步及正式資料推送工具；資料更新不能只改顯示點位而略過 GPX 與地形一致性。
