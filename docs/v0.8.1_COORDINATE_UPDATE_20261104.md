# v0.8.1 座標與連續路徑更新（2026-11-04）

## 本次結果

- 匯入86筆完整座標（81筆屬現行步行用途、5筆僅車行而不顯示）；TWD97反算後用獨立正算公式驗證，誤差不超過1公尺。
- 21筆忽略／忽視停止查座標，其中20筆仍在現行目錄，1筆為先前已退休的G19節點。
- G17刪除荖濃溪底營地、大水窟山三岔路、水源及6筆相連方向；沒有捏造替代邊或方向時間。原資料保留於retirements來源紀錄。
- Q013採補填座標，Q053顯示名改為松泉崗/天巒池登山口，舊名保留別名。
- 現行724點：622點有座標與海拔，20點使用者忽略、26點僅車行、56點仍待定位。
- 保留原有452組線形（包括雪山種子），現在共654組參考線形，其中42組有明確順序的viaNodeIds跨越未定位中間點。
- 原95組缺端點／線形的相鄰邊中，78組已由連續跨點線形覆蓋；另17組仍缺定位錨點或來源線形，詳見下表。
- 剖面依每日地圖配色、淡色填滿、清楚表頭及距離／升降統計；提供2倍解析度PNG下載、圖片複製與不支援時的替代提示。
- 跨點線形只在最後錨點列一次合計；中間列顯示分段待定位。行程、手填時間、方向基準時間均保留。

## 來源疑點修正

林道鞍部原配到梅蘭林道，距南一段相鄰點約30公里，已改用石山秀湖牌旁四叉路口的Happyman航點群。丹大林道盡頭原誤配西巒山區，已撤銷錯誤座標，並作為未定位中間節點跨過。原值、理由及來源保留於owner-update-source-corrections.json。

使用者補填的登山口／營地標記與步道線形錨點仍分開：本次對使用者指定點允許最多300公尺投影，未繪製標記到步道的離徑連接線。偏移量保存於routingAnchors及新路段anchorOffsetsMeters。歷史GPX的匹配仍採120公尺。
