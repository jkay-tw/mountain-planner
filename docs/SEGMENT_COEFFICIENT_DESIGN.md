# 分段上河係數：設計與驗收草案

狀態：已在整合分支實作 Preview，待 iPhone 實機驗收；正式版未變更。

整合版沿用 Issue #6 的捲動位置保護與手機出發時間輸入修正。Preview 使用獨立暫存，行程 schema 維持 v1，逐段新增可選的 `coefficient` 與 `referenceKind`。舊行程載入時固定原規劃分鐘數；日預設係數只影響後續建立的路段。

- 每日預設係數只套用到新建立的上河路段，含尋路與快速加入的中間段；每段可獨立編輯，顯示規劃時間在前。
- 顯示兩位小數；鍵盤上下鍵每次改變 0.10，以當前實際值為基準（0.85 → 0.95），調整後保持輸入焦點。
- 慢速／重裝／一般條件依來源有無顯示，切換參考時間，保留該段係數；手動無上河時間的路段仍輸入分鐘數。
- 舊檔與既有暫存轉換須保留每段原規劃時間；精度損失不可改變時間。使用者主動修改該段係數後才重新計算。
- 新增 Day 2 以後預設銜接前日；舊行程保留原設定。前日未有終點時保留待銜接意圖，前日後續新增或變更終點時需同步，且不得覆蓋使用者原行程。
- 保留撤銷、重做、手動時間、分段重建、已存來源、跨日與條件式來源；匯入／匯出 JSON 與 Excel 的計算一致。

## 驗收

舊檔自動與手動時間原值不變；新加入路段依加入時係數固定；含多段自動路徑、快速加入、條件切換、0.85 上下鍵及焦點、連續修改、跨日空前一天與後續編輯、取消銜接、手機／電腦、備份匯入匯出與 Excel，以及無上河時間手動段。正式版隔離，Preview 測試並經使用者驗收後再處理發布。
