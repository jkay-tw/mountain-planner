# v0.8.2 版面精簡

- 剖面繪圖區固定200 SVG單位，標籤最多上下各兩排；名稱一行，距離與海拔合併一行。左右位移限制100單位，無法排列時整圖改編號及三欄對照，不再無限往上／下堆疊。
- 繪圖區與資料完整保留，PNG下載／複製採相同SVG版面。圖下編號對照隨節點數增長，這是實際資訊所需空間，不會用大片空白或長引線撐高剖面。
- 地圖控制同列：載入／縮放、GPX、節點標籤、每日剖面；路徑摘要與Day開關同列，窄螢幕自然換行。
- 每日剖面預設收合，按「每日剖面」展開；來源僅顯示OpenStreetMap與DEM署名，完整說明仍可展開。
- 地圖本體桌面360px、手機300px。頁首說明縮為「切換圖組不影響行程，編輯自動儲存。」
- 不修改座標、方向時間、路線資料與行程暫存。

驗證：117項JavaScript、95項Python通過。密集節點案例驗證標籤位置有界、同排不重疊，以及編號模式保留所有節點名稱與數值。依使用者提供12點里程／海拔重現的剖面已渲染檢查；線上操作在Preview部署後驗證。正式版根目錄不更新。
