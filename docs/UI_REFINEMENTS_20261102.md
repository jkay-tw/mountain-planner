# v0.7.29 Preview：行程欄位、手機版、快速加入與列印

## 已同意的呈現

- 桌面版在時間與備註之間新增距離／升降欄，以 km、↗、↘ 顯示估算值；原備註維持可編輯。
- 手機版（760px以下）每個行程點分成地點／時間、距離升降、備註與⋯三列；休息項目亦有明確欄位，避免隱含欄擠出畫面。
- 每日統計旁的「查看高度剖面」可直接展開，不依賴 Leaflet 或地圖載入；圖上標示沿途節點。開關不改變行程或備註。
- 地圖常駐節點名稱與 DEM 估算海拔；「詳細資訊」增加灰色小字 `TWD97 (E, N)`，點擊節點一律可查看完整資訊。使用 TWD97 / TM2 121分帶，顯示取整公尺；WGS84與TWD97在此DEM顯示精度視為等效，不宣稱測量精度。

## 快速加入

`quickAddCandidates` 從當日最後一個正式 location 沿全域、已核對、已開放於路網的 walking 有向邊找一段／兩段；不依目前瀏覽圖組篩選，不使用 OSM 背景線，不納入車行或未核實邊。已確認的11組長短重疊關係先展開，再計算兩段範圍，不把長路段誤認成直接鄰點。

直接相鄰節點先顯示；兩段內選項放在「更多鄰近節點」。岔路各方向均列出，回頭方向在有已核對的反向邊時保留；不重返目前點形成兩段空迴圈。相同目的地不同途經節點分開列出，按鈕註明「經…」；同名不同Node ID補圖組區別。

點擊時重新驗證起點與路段，依該按鈕的確切途徑加入，中間點與逐方向時間／條件式時間保留，不重新改走另一條最短路徑。新增、刪除、切日、復原與末點改變後，候選重新產生；手動末點不假裝連通。

## Excel

共用同一個 exportExcel，不依裝置或螢幕寬度切換格式。欄位為地點／抵達／規劃分／上河分／係數／距離km／上升m／下降m／備註／來源。F、G、H為數字，不把單位或圖示寫進數值；每日統計在同欄加總，缺漏明示只計已知部分。休息與原有註記保留。

預設A4直向（paperSize9）、一頁寬（fitToWidth1）、高度不限（fitToHeight0）；窄欄與窄邊界，前3列表頭重複列印。備註換行依長度增加列高；每日備註也計入換行。相較舊版不再將地形估算附加到備註文字。

實際執行產品 ExcelJS 4.4.0 匯出，重新讀取 XLSX 與 ZIP/XML 驗證：A4直向、一頁寬與無高度限制、列印範圍A:J、重複表頭、數字欄與每日總計均正確。內部渲染器缺少中文字型，故不將其中文字形呈現當成 Excel 原生列印驗收；實際印表機分頁仍可能受驅動與字型影響。
