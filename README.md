# Mountain Planner｜登山行程快速規劃器

靜態網頁版登山行程規劃工具。以官方上河步程資料為基準，套用個人係數、休息與手動節點，自動生成多日行程並匯出 Excel。

## 目前功能
- 依上河圖 Gxx 分群
- 先選起點與重要節點，自動以「上河時間總和最短」補齊中間節點
- 每段保留官方上河時間，規劃時間可個別修改
- 每段顯示有效上河係數至小數點後 2 位
- 可插入休息，顯示休息開始與「休息至」時間
- 可插入手動節點，前後路段改由使用者自行輸入時間
- 手動路段不納入上河係數
- 休息與手動節點可拖曳
- 手動節點移走後，原本重新相鄰的官方 A→B 路段會自動恢復官方步程、係數與來源
- 支援多日 Day Cards、每日獨立出發時間
- 後一天可先規劃；可設定與前一天終點銜接
- 每日統計行進、休息、總時間與加權平均上河係數
- 多工作表 Excel 匯出

## 資料原則
官方上河時間永遠只作為唯讀基準，不會被使用者的規劃時間覆寫。手動節點與手動路段屬於個人行程資料，不會回寫上河原始 dataset。

Prototype 目前只有 G06 白姑大山，資料狀態為 `checked`，尚未升級為完整 `verified` master dataset。
