# Mountain Planner｜登山行程快速規劃器

靜態網頁版登山行程規劃工具。以官方上河步程資料為基準，自動補齊路徑，再依每天速度、休息與手動節點微調。

## v0.5 介面與行程功能
- 初始狀態為 1 天、未選上河圖、日期空白
- 可設定整趟出發日期，Day 2 起自動遞增日期
- 每日獨立設定出發時間與預設上河係數
- 行程列改為：地點｜路段資訊｜抵達時間｜備註｜操作
- 山頭顯示於地點名稱前，水源顯示於名稱後
- 未選取的 ⛰ / 💧 大幅淡化
- 手動節點名稱可直接在列內編輯
- 路段分鐘輸入框以 3 位數為主要顯示寬度，隱藏上下微調箭頭
- 休息與手動節點使用獨立拖曳把手，並可拖入節點間的 drop zone
- 每日與全部清除皆為可見主按鈕並有二次確認
- JSON 行程檔按鈕名稱簡化為「匯出 / 匯入」
- 自動暫存在瀏覽器 localStorage
- 複製文字格式維持 D1：時間 地點→時間 地點…，不受網頁欄位順序影響

## Excel
所有天數整合在同一工作表。

每日標題靠左，格式包含：
- Day
- 日期（若有設定）
- 出發時間
- 結束時間

行程列：
- 規劃時間：純分鐘數字
- 上河時間：純分鐘數字
- 係數：純數字

每日統計列：
- 規劃時間欄：總時間，以 Excel `[h]:mm` 真實時間值儲存
- 上河時間欄：總上河時間，以 Excel `[h]:mm` 真實時間值儲存
- 係數欄：總時間 ÷ 總上河時間
- 備註欄：行進 h:mm、休息 h:mm
- 不另外統計手動時間

## 行程儲存
行程可匯出為 `.mplan.json`，內容包含 routeId、datasetVersion、出發日期、每天設定、節點、官方時間快照、手動時間、休息、備註與圖示標記。

官方上河時間永遠只作為唯讀基準，不會被個人規劃時間覆寫。

Prototype 目前只有 G06 白姑大山，資料狀態為 `checked`。
