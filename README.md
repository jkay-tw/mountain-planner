# Mountain Planner｜登山行程規劃器

以台灣上河步程資料為基礎的靜態網頁行程規劃工具。

- [開啟正式版 v0.7.25](https://jkay-tw.github.io/mountain-planner/)
- 開發分支：`feature/v0.7-node-identity`
- [專案導覽與測試指令](docs/PROJECT_GUIDE.md)

## 主要功能

- 在同一套路網中瀏覽已收錄的 G02～G20 路線群組，切換圖組不清空行程。
- 依已收錄的有方向步行路段尋路，並以每日上河係數或自行輸入的時間規劃多日行程。
- 無法連通時保留節點，提供手動連接與估時；車行不進入步行尋路。
- 設定每日出發時間、休息、備註，並匯入／匯出 `.mplan.json`、匯出 Excel。
- 各瀏覽器分頁獨立暫存行程；一般新分頁載入最後修改的共用備份。重要行程仍可匯出檔案備份。

## 資料範圍

目前整合使用者已人工核對的候選資料，涵蓋 24 個群組、731 個節點與 1,426 條唯一方向步行邊；130 個車行方向另存，不參與步行尋路。這是已提供候選資料的核對結果，並不表示官方每張圖的所有路段均已收錄。資料來源、人工修正與跨圖身分紀錄位於 `data/audits/` 和 `data/crosswalk-reviewed.json`。

資料與時間為行程規劃參考，不代表即時路況或現地導航。原始上河時間與使用者的規劃分鐘數分開保存。
