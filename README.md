## 主要功能

- 在同一套路網中瀏覽已收錄的 G02～G20 路線群組，切換圖組不清空行程。
- 依已收錄的有方向步行路段尋路，新路段依加入時的每日預設係數固定，可逐段調整係數並切換一般／慢速／重裝參考時間；無上河時間的路段可手動估時。
- 無法連通時保留節點，提供手動連接與估時；車行不進入步行尋路。
- 設定每日出發時間、休息、備註，並匯入／匯出 `.mplan.json`、匯出 Excel。
- 全路網已定位節點的參考線形、DEM 海拔、每段與每日距離／上升／下降、高度剖面，以及含高程的 GPX。
- 前後兩段快速加入，只顯示「＋ 名稱」；手機備註換行；Excel 採 A4 直向、獨立距離／升降欄與時:分格式。
- 各瀏覽器分頁獨立暫存行程；一般新分頁載入最後修改的共用備份。重要行程仍可匯出檔案備份。

## v0.9.0 更新

- 路網小地圖支援附近節點名稱、引線與目前位置；密集處採示意避讓，連續快速加入保持展開。
- 快速加入顯示經由節點與返回方向，手機休息／手動點支援觸控拖曳。
- 調整桌面工具列與窄視窗選單，使用說明以醒目底色及白字呈現。
- 重製圖文說明，依建立行程流程解說，提供局部截圖、功能框線、係數範例與可放大圖片。
- 座標同步守門、來源檢查與快取更新工具已收錄；資料更新仍須通過重算及驗證。

## 資料範圍

目前整合使用者已人工核對的候選資料，涵蓋 24 個群組、724 個現行節點與 1,412 條唯一方向步行邊；130 個車行方向另存，不參與步行尋路。這是已提供候選資料的核對結果，並不表示官方每張圖的所有路段均已收錄。資料來源、人工修正與跨圖身分紀錄位於 `data/audits/` 和 `data/crosswalk-reviewed.json`。

現有資料：622 個定位節點有海拔、654 組參考線形（含42組跨未定位中間節點的連續線形）。車行專用點及指定忽略點不顯示座標。尚有17組路段缺定位錨點或來源線形，完整清單見本版說明；不以直線補接。

資料與時間為行程規劃參考，不代表即時路況或現地導航。原始上河時間與使用者的規劃分鐘數分開保存。
