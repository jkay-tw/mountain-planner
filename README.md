# Mountain Planner｜登山行程快速規劃器

靜態網頁版登山行程規劃工具。以官方上河步程資料為基準，自動補齊路徑，再依每天速度、休息與手動節點微調。

## 目前功能
- 依上河圖 Gxx 分群
- 每天第一個加入的節點直接視為起點
- 選重要節點後，以「上河時間總和最短」補齊中間節點
- 單一 row 顯示抵達時間、節點、規劃時間、上河時間/係數、山頭/水源與備註
- 每天可獨立設定預設上河係數
- 每段規劃時間可個別覆寫
- ⛰ / 💧 未選取時弱化、選取後明顯顯示
- 休息與手動節點可由專用拖曳把手移動，不影響文字選取
- 節點之間有 drop zone，可把休息／手動點插入任意位置
- 手動節點移走後，若原 A→B 再次相鄰，會恢復官方 A→B 步程與來源
- 每個節點與每天皆可填寫備註
- 每日主按鈕可清除當日行程；頁面主按鈕可清除全部行程，皆有二次確認
- 一鍵複製純文字行程
- Excel 全部天數整合在同一工作表
- 自動暫存在瀏覽器 localStorage
- 可儲存／匯入 `.mplan.json` 行程檔

## 行程儲存格式

使用 JSON，檔名例如：

```text
G06_白姑大山.mplan.json
```

內容包含：
- format / schemaVersion
- 儲存時間
- routeId
- datasetVersion
- 每日出發時間與預設係數
- 節點順序
- 官方時間快照
- 手動修改時間
- 手動節點
- 休息
- 備註
- 山頭 / 水源標記

匯入舊資料版本時，系統會提示目前 datasetVersion 不同。行程檔保留儲存當下的官方時間快照，不會因資料庫版本改變而默默改寫舊行程。

## 純文字行程格式

```text
D1：08:00 奇萊登山口→10:00 奇萊主北叉路口→11:00 奇萊北峰⛰→15:00 月型池。

D2：06:00 月型池→08:25 磐石山⛰→09:20 磐石山西峰⛰→16:10 三叉營地。
```

休息不另外列入文字版，但會反映在後續抵達時間。

## 資料原則
官方上河時間永遠只作為唯讀基準，不會被使用者的規劃時間覆寫。手動節點與手動路段屬於個人行程資料，不會回寫上河原始 dataset。

Prototype 目前只有 G06 白姑大山，資料狀態為 `checked`，尚未升級為完整 `verified` master dataset。
