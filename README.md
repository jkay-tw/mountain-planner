# Mountain Planner｜登山行程快速規劃器

靜態網頁版登山行程規劃工具。以官方上河步程資料為基準，自動補齊路徑，再依每天速度、休息與手動節點微調。

## 目前功能
- 依上河圖 Gxx 分群
- 每天第一個加入的節點直接視為起點，不需額外設定起點
- 選重要節點後，以「上河時間總和最短」補齊中間節點
- 所有行程點可刪除；刪除後重新建立相鄰路段
- 每段保留官方上河時間，規劃時間可個別修改
- 每段顯示有效上河係數至小數點後 2 位
- 每天可獨立設定預設上河係數
- 個別手動修改過的官方段不會因每日預設係數變更而被覆寫
- 可插入休息；時間軸顯示的是休息結束時間
- 可插入手動節點，直接在時間軸內改名稱與前後時間，不跳系統視窗
- 手動路段不納入上河係數
- 手動節點移走後，若原 A→B 再次相鄰，會恢復官方 A→B 步程與來源
- 節點可標記 ⛰ 山頭、💧 水源
- 每個節點與每天皆可填寫備註
- 支援多日 Day Cards、每日獨立出發時間
- 後一天可先規劃，也可與前一天終點銜接
- 每日統計以 hr / m 顯示行進、休息、總時間與加權平均上河係數
- 一鍵複製精簡純文字行程
- Excel 全部天數整合在同一工作表，中文以微軟正黑體為主、數字欄以 Calibri 呈現

## 純文字行程格式
```text
D1：08:00 奇萊登山口→10:00 奇萊主北叉路口→11:00 奇萊北峰⛰→15:00 月型池。

D2：06:00 月型池→08:25 磐石山⛰→09:20 磐石山西峰⛰→16:10 三叉營地。
```

休息不另外列入文字版，但會反映在後續抵達時間。

## 資料原則
官方上河時間永遠只作為唯讀基準，不會被使用者的規劃時間覆寫。手動節點與手動路段屬於個人行程資料，不會回寫上河原始 dataset。

Prototype 目前只有 G06 白姑大山，資料狀態為 `checked`，尚未升級為完整 `verified` master dataset。
